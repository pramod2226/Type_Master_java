#Project Overview
##Type_Master_java
is a simple, interactive, console-based typing practice application
developed using Core JAVA. The main objective of the project is to help
users practice typing, improve their typing skills through an interactive
text- based exercise.

The application displays a predefined paragraph stored in an external
text file and asks the user to type the same paragraph.
After receiving the user's input, the program
compares the entered text with the original paragraph and provides
feedback based on the typing performance.

If the user types the entire paragraph correctly, the program displays an "Excellent!"
message.

This project demonstrates fundamental Java programing concept such as file handling,
user input, conditional statement, string comparison, and console-based application development.
